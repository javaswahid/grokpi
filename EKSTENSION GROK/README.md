# Grok + Veo Token Extractor

Extension Chrome untuk mengambil:

- `sso-rw` atau `sso` dari Grok
- `x-userid` dari Grok
- `__Secure-1PSID` untuk Veo atau Gemini

## Lokasi

Folder extension:

`D:\APLIKASI MASJAVAS\Ekstensi chrome grok\EKSTENSION GROK`

## File

- `manifest.json`
- `popup.html`
- `popup.js`
- `background.js`
- `icon.png`

## Cara pasang

1. Buka `chrome://extensions/`
2. Aktifkan `Developer mode`
3. Klik `Load unpacked`
4. Pilih folder extension ini

## Cara pakai

1. Login ke `https://grok.com/` atau `https://grok.x.ai/` untuk token Grok
2. Login ke `https://gemini.google.com/` untuk token Veo
3. Klik icon extension
4. Pilih tab `Grok Token` atau `Veo Token`
5. Klik tombol ambil token atau pakai shortcut `Ctrl+Shift+G`
