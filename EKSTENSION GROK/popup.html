Chrome Extension v1.3

Grok + Veo Token Extractor

Ambil token Grok dari grok.com atau grok.x.ai, lalu ambil token Veo dari gemini.google.com dalam popup yang sama.

Pilih token yang ingin diambil.

Shortcut tersedia di Chrome Commands: Ctrl+Shift+G. Jika data belum muncul, pastikan akun sudah login di halaman target lalu refresh sekali.
